# Intelligent Translator 
Translator that can fix its own translations with an open source model, making translations easier and intelligible.

## The Problem (Personal)
I am Chinese American, but my Mandarin is pretty bad. Maybe a little bit better than a beginner, but I can only speak and understand it, I cannot read or write in the language.

With some of my family, many of them know English. I can communicate with them using a mix of both English and Mandarin, which lets us communicate fine most of the time. However, with the older members of my family, they either don't know English at all or know very little. Communication with my grandparents can be very jumbled and difficult. 

I started this project to make it easier for me to communicate with them, and I hope this project helps other people who struggle with a similar problem.

## The Problem (General)
With many translators, like Google Translate, it is a common problem for translations to be confusing. Grammar, slang, pronouns, etc. can be mixed up during translation. 

This project solves this problem (at least tries to) by using an open source model to polish and correct a translation so it makes sense to the person reading/hearing it.
